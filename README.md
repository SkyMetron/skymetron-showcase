SkyMetron é um sistema operacional de IA local, projetado para um único owner.  
Nenhum dado sai da sua máquina. Nenhum servidor externo necessário.

## Instalação

Baixe o instalador mais recente:

👉 **[Releases Oficiais →](https://github.com/SkyMetron/skymetron-releases/releases/latest)**

`powershell
# Instalação silenciosa
SkyMetron-Setup-<version>.exe /S /D=C:\SkyMetron
`

## Recursos

- **Login-first**: GitHub Device Flow, owner-only
- **Local-first**: DPAPI, sem nuvem
- **Doctor**: Diagnóstico pós-login
- **Workspaces**: Volumes nomeados isolados
- **Agentes**: 10 agentes especializados
- **Graphify**: Camada estrutural (planejado)
